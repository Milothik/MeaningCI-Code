# MeaningCI Code benchmark report

## Hypothesis

Behavioral decision probes may detect code regressions with fewer false alarms than syntax changes, and may complement tests. They must beat simpler direct decisions to justify their complexity.

## Dataset and methodology

Pinned QuixBugs revision `4257f44b0ff1181dedaedee6a447e133219fcebf`. All 31 JSON-compatible programs: 31 original defects plus 62 mechanically generated preserving controls. Nine graph-object programs are explicitly excluded by the initial adapter. Program-disjoint 15/8/8 development/validation/test split. Code comments/docstrings removed symmetrically, including alternate corrected implementations. Three inputs chosen by input-only hash; four fixed behavioral predicates per input. Providers never receive gold expected outputs or labels.

## Paired analysis

- meaningci-jsd minus jev-direct: accuracy difference -0.500, program-cluster 95% CI [-0.750, -0.250], exact McNemar p=0.0018, exact program-level sign-flip p=0.0312; discordant wins/losses 1/13.
- meaningci-jsd minus tests-budget-3: accuracy difference -0.583, program-cluster 95% CI [-0.833, -0.292], exact McNemar p=0.0005, exact program-level sign-flip p=0.0312; discordant wins/losses 1/15.
- meaningci-jsd minus tests-full: accuracy difference -0.583, program-cluster 95% CI [-0.833, -0.292], exact McNemar p=0.0005, exact program-level sign-flip p=0.0312; discordant wins/losses 1/15.
- meaningci-jsd minus ci-tests-full: accuracy difference -0.625, program-cluster 95% CI [-0.833, -0.375], exact McNemar p=0.0001, exact program-level sign-flip p=0.0156; discordant wins/losses 0/15.
- meaningci-jsd minus meaningci-label: accuracy difference 0.083, program-cluster 95% CI [0.000, 0.208], exact McNemar p=0.6250, exact program-level sign-flip p=0.5000; discordant wins/losses 3/1.

Eight held-out clusters give low statistical power. Tests share pairs within a program; McNemar's pair-independence assumption is imperfect here. Bootstrap clusters preserve dependence. Multiple comparisons are exploratory, not confirmatory.

## Ablations and probe coverage

Compare direct judgment, label flips and full distributions on the same batch/model; compare three-input execution with the full official input suite. Fixed confidence gate 0.65; JSD threshold chosen on validation only, saved in frozen_thresholds.json. ORACLE input coverage: 26/31 original defects; ORACLE predicate coverage: 15/31. These upper-bound diagnostics are evaluator-only and not retrieval/model predictions.

## Failures and cost

Every pair has a trace including source/candidate execution, expected outputs (evaluator only), native vectors if measured, exceptions and timeouts. logs/failures.json preserves upstream fixture mismatches, timeouts and provider errors. Combined batches share code context and collection overhead. Raw native usage and capture wall time are retained; standalone per-method costs/latencies and a general-purpose LLM baseline are not measured.

## Limitations

- Only 8 test program clusters: exploratory confidence intervals
- 31 small public algorithms, possible training contamination
- Jev direct is same decision model, not a general LLM judge
- Combined collection batches do not establish per-method cold latency/cost
- Controls generated by this experiment, not supplied by QuixBugs
- No equivalence guarantee or production-code evidence

## Measured collection resource usage

93 native Jev requests / 2325 native decisions; 463936 input tokens and 88747 output tokens. Combined-batch engine p50 80.0 ms, p95 124.0 ms; UI collection p50 2272.0 ms, p95 3053.0 ms (91 timed captures; two manual-inspection/recovery captures excluded). These are combined experimental batches, not standalone method service latency. No invoice/tariff was verified; monetary cost remains unavailable.

## Interpretation and next design

The fixed input-only predicates miss many exact-value changes even under perfect interpretation. The 0.65 reliability gate plus requiring every remaining probe to be determinate produces many abstentions; this is an honest coverage limit, not a PASS. Distribution shifts can also flag preserving controls. Source A and candidate B are jointly visible, and source answers may change with candidate context; source-independent reuse has not been validated. Do not deploy this battery as an autonomous CI gate. Prefer execution tests; investigate direct Jev as supplementary triage, with its missed defects and uncertainty retained. A future source-grounded scenario generator needs a new protocol and independent production-code benchmark, rather than retuning these test cases.

## Conclusions

MeaningCI JSD correctly classified 9/24 held-out pairs, direct Jev 21/24, and full execution tests 23/24. These small public-program results do not establish production readiness or a commercial advantage. The added probe/distribution architecture did not beat direct judgment in conservative accuracy.
